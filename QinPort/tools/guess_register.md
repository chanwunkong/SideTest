# 還在用猜的／沒移植的遊戲規則清單（2026-11-22）

來源：engine/src 裡的 `shortcut:` 註解共 約 300 處（main.c 201、story_rt 15、viewport 13、unit 14、air 11 …），大多是平台層（視窗、音效、網路同步）。
下面只列**會影響遊戲玩法**的，附狀態與下一步。「已對照」= 讀過原版反編譯碼確認等價或已改。

## 仍是猜的／自訂（依對玩法的影響排序）
1. ~~開局左右手技能~~ **已改原版（2026-11-22）**：技能物件的 `UI_Cur` 位元（1 右手、2 左手）在加技能時決定手（Poq 0x485f80 的 hand 低兩位 ← 封包 0x524 ← EasyRPG.dll 0x10041130 送出 `UI_Cur`）；story/skill/主角/*技能/ 只有各職業第一招 UI_Cur=3，故開局兩手 = 該招（main.c `hero_default_hands`）。先前追的 `DefaultSkillID0/1`（Poq 0x51c8c0）只是客戶端把選擇存進本機設定，不是開局來源。之後換手由客戶端回報伺服端 UI_Cur（0x1023），伺服端程式不在檔案裡，沿用我們自己的存檔。**只編譯＋單元測試，沒在瀏覽器開新角色看。**
2. ~~戰鬥姿態持續時間 FIGHT_TICKS=300~~ **NPC／怪物改原版（2026-11-22）**：退戰只在 `npc_pick_target`（Poq 0x490430：沒候選目標＋建構 0x485270 設的 +0x520=1 旗標，累積拍%5==1 或 force 才送命令 11 參數 0；`battle_return` 初值補成 1），NPC組不再用 300 拍計時。**玩家組（主角／隊友）仍用 300 拍**：原版其退戰由伺服端送狀態0（Poq 0x522 → 0x48d950），伺服端不在 Poq／EasyRPG.dll（EasyRPG.dll 0x10041930／0x1003be30 只是轉送），時長查不到。**只編譯＋單元測試，沒在瀏覽器看怪物退戰。**
3. ~~怪物閒逛半徑 MON_WANDER=4~~ **已改原版（2026-11-22）**：怪物由 Poq 0x44f580 建 SInitCha（建構 0x44eec0：行走休息 0、範圍 0）只把平時邏輯設 10；0x492730 的「其他邏輯」分支 = 不閒逛，只在偏離出生格時偶爾（1/100 每拍）走回（main.c `mon_make` 的 `.logic = 10`，`MON_WANDER` 移除）。先前以為的「性格欄 4*2」與閒逛無關。「沒劇情時怪物都算同一 NPC 組 10000」仍是自訂（有劇情時用 G_AIGroup）。**只編譯＋單元測試，沒在瀏覽器看。**
4. **can_eat**：先當食物（51）與書（49）能吃。DLL 只有預設 0 與一處讀取（0x10016be0），沒有地方用名字設成 1，疑似經由屬性代號表設定，沒對上。
5. ~~召喚／馴服／分身細節~~ **已改原版（2026-11-22 續）**：召喚（EasyRPG.dll 0x100355d0）放在攻擊位置（G_PosX/Y = 角色出手結算點 = 出手者所在格，Poq 0x43c4f0 type 15 → 0x43ab20；被佔了 actor_place 找空格）、等級同召喚者（0x10056120）；數量與「先移掉別種」數的是召喚者整隊 istrap 20 的成員，且只有前 6 種（k<6）會 AddMember（0x10037850），所以後 4 種（朱厌等，表上 istrap 空白）不被數也不被移 = 沒有數量上限（原版行為，不是漏做）。馴服（0x10035370）：Friend<4 → 訊息 5000、istrap≠10 → 0x1400、隊上 istrap 10 已滿 271 → 0x1389、目標已有隊伍 → 0x138a，成功才 Friend=1 加入。分身（0x10034140）：施放者整隊已有 IsCloned 就擋（訊息 0x1394，所以分身自己放分身也被擋）、放在攻擊位置、只設 Friend 1（不設 G_AIGroup、不設主人）。仍自訂：分身／陷阱的等級用施放者的（原版 FUN_10059870 不設，初值來源沒查到）；Hand 只有主角有，隊友施放分身當刀；分身 G_EquipStr3→1 用 clone_equip 照施放者裝備算。**只編譯＋單元測試（skilltest 新增召喚／馴服／分身斷言），沒在瀏覽器看。**
6. **擊退**（hit_react）：原版多一個角色表 +0xa4 條件（意義沒查）；主角的 B_C_JDR、B_C_DJHF 原版從模板讀，這裡當 0。
7. ~~技能作用範圍（單位打到誰）~~ **已改原版（2026-11-22 續）**：舊的「依技能範圍估」只寫在 type 16 分支，而 0x43c4f0 的 type 16 的 0x14／0x16 放的是殘影（CPhantasmObj 0x43dd90／0x43e100，不打人），那段本來就是死碼，已刪。角色出手的命中觸發（type 0）現在照 0x438a00：id 0、2、3、0x14 掃前方格、5 自己點、6~10 周圍 64~320、11／13 目標點第一個、12 目標周圍 0xc0，全走 unit_hits／hit_find（0x439fb0，原本招式單位就用這份）；只有 id 30（case 0x1e 直接打目標）與 type 15（結算，目標 −1）留在 method_hits。副作用：近戰不再「只要是攻擊目標就打到」，要目標在出手方向的前方格內（原版如此）；技能自己的狀態只在打中人時加（原版封包 0x13b 只在命中／結算時送）。**只編譯＋單元測試＋walktest，沒在瀏覽器看近戰手感，請留意貼身近戰有沒有打不到。**
8. ~~打物件（目標種類 21..29）~~ **已改原版（2026-11-22 續）**：旗標是招式表 MethodMdl 的 Reserve4（Method +0x36，Poq 0x4911b0；玩家點選目標的 0x457xxx 同欄位：1／2／4／8／0x10／0x20／0x40 各管一種目標）。NPC 主 AI（npc_main_ai）目標是物件（種類 0x15~0x1d）而招式 Reserve4 沒有 4 → 清目標、清排隊命令、回平常（0x48e8d0、0x486e70、0x496550(1,0,0,0)；虛擬 +0x48(1,1) 的清除副作用仍沒做）。玩家點選物件的那段（0x457xxx）沒移植。**只編譯＋單元測試，沒在瀏覽器看。**
9. ~~隊友／分身選技能~~ **已改原版（2026-11-22 續）**：0x4906c0 本來就走角色技能鏈（怪物與隊友共用），規則（wManualID 0/3/1/4 分組、Reserve3 0/2/3/4/5、遠程招一半機率）已在 mon_pick，現在隊友與分身用同一份（chain_pick，走技能鏈含沒有技能列的模板普通攻擊）。仍自訂：節點 Enable 原版由伺服端依精氣更新（0x1004c2a0），這裡用 skill_usable 代替。**只編譯＋單元測試。**
10. **死亡到開死亡視窗 180 拍**：查過仍是自訂。Poq 0x4f5240（開 JM513）只由視窗狀態機 0x448d20 進入狀態 5 時（0x44d340／0x44d470）呼叫，誰要求狀態 5 的訊息來自伺服端（死亡後的延遲在 Poq／EasyRPG.dll 裡找不到），與第 2 項同樣屬於伺服端、查不到。
11. ~~小動物逃跑~~ **已改原版（2026-11-22 續）**：actor 版小動物（main.c）改照 0x49b6e0（air.c／sur_flee 已是原版）：logic 1 = WhatDir8（威脅→自己）後 GetFleePos 步長 5 格；其他 logic = 路線上離威脅曼哈頓距離最遠的路點，沒路線就保持原目標（原本是連續角度 5 格）。高速仍用旗標 0x10000（×3/2）代替 BeastieMdl 高速。死亡的 +0x8b／30 拍餘數條件之前已對照。**只編譯，沒在瀏覽器看。**
12. ~~NPC 逃跑步長 3 格~~ **已改原版（2026-11-22 續）**：GetFleePos 的隱藏步長由呼叫點機碼核對：0x490fc0（恐懼逃跑）= +0x55d／3 + 1（= seek_adjust/3+1）；0x491af0（退開）= 呼叫端傳的 dist；0x4911b0（射程退一步）= 技能射程 − 距離 − 2（機碼 0x4917a5 的 ecx）。（另 0x4911b0 本來就對，6095 行的 SkillUnit.min+1 是 8/9 追近那處。）
13. **成套裝備（套裝）數值**：原版怎麼算沒查，現照單件。
14. **拖放裝備的部位檢查**、**SpeType**：照部位表推的／當 0。
15. **升級後劇情人物的 Upgrade_ 屬性重算**（story_rt）：隊友升級的 HP／MP 用引擎的升級表。
16. **其他基底初始化（0x1005cd60、0x1005cab0、0x1005d4a0、0x1005cd40）**：預設屬性沒照原版設。
